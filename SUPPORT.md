# Fill Documents support

English · [한국어](SUPPORT.ko.md)

Publisher: **yback** ([GitHub profile](https://github.com/yback1223)).

Report installation problems, reproducible bugs and feature requests through [GitHub Issues](https://github.com/yback1223/fill-documents/issues). Include the version, operating system, `doctor` output, document format and error code. Do not post real customer documents, personal data, signatures, account details or secrets in public issues. Where possible, attach a minimal example with no personal information.

This is a public open-source project. Response times and recovery of individual documents are not guaranteed. See the [README](README.md) for supported features and current limitations.
