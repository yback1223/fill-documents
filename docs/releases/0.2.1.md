# 0.2.1 release record

2026-10-08 (Asia/Seoul).

## Changes

English is the default for marketplace descriptions, suggested prompts and public documentation. The Korean listing translation remains included. The main README, plugin README, privacy notice, terms, support page and changelog have linked Korean versions.

Document-processing behavior is unchanged from 0.2.0. The runtime CLI's reported version is updated to 0.2.1. Original code and templates remain MIT licensed; third-party notices, fonts and binaries are retained. The release remains free, with no in-product payments and availability in all supported countries.

## Verification

- `npm run build`: both distribution ZIPs generated successfully.
- `npm run validate`: both final ZIPs passed 32 isolated template fills and 8 long-content flows with network and child-process execution blocked. Manifest consistency, version reporting, original-file preservation and Korean filesystem paths are included in this check.
- `claude plugin validate ./plugins/fill-documents --strict`: passed.
- ZIP inspection confirmed English default descriptions and prompts, a nonempty Korean listing translation, both plugin README languages and matching portable/Codex metadata.
- Checked reciprocal English/Korean links for the five public documentation pages.
- `git diff --check`: passed.

The 282-test unit suite was not rerun locally for this documentation/metadata patch. The package validation above exercises the unchanged document-processing paths. Native Hancom Office and Microsoft Word rendering was not tested.
