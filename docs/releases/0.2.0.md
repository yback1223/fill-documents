# 0.2.0 공개 배포 기록

2026-10-08. 브랜드·GitHub 저자 yback, 사용자가 승인한 OpenAI 인증 개인 게시자, 자체 코드·서식 MIT, 무료·제품 내 결제 없음, 지원 가능한 모든 국가 배포.

## 공개 기능

지원되는 HWP·HWPX·DOCX·PDF 명시 필드 채우기, 16종 기본 서식, 서식 등록, 원본을 덮어쓰지 않는 새 파일 저장을 제공한다. 이번 버전은 제한된 장문 이어쓰기, 전체 작성 절차, 준비본 해시에 연결된 작성 범위 보고, DOCX 탭 정지점 보존을 추가한다.

일반 빈칸 자동 발견, 완성본의 범용 재작성, 지정 부분만 수정하는 공통 편집 기능은 제공하지 않는다. 스킬의 전체 작성 지침과 CLI가 실행할 수 있는 범위를 구분한다. 문서별 준비·편집·검수로 만든 예시를 범용 기능으로 표시하지 않는다. 한컴오피스·Microsoft Word 자체 앱의 표시·편집·인쇄는 미검증이다.

## 원격 배포 및 심사

- 릴리스 커밋: `2f11c290d7837a9c76be94c86b350049ecde16d5`, 공개 태그 `v0.2.0`.

- 두 자체 marketplace 및 공개 manifest·README·개인정보 안내를 인증 없이 읽고 로컬 파일과 바이트가 같음을 확인했다.
- Anthropic 디렉터리: 저장소 검증 통과, 신청 초안 저장. 글꼴·바이너리·자격증명 탐지 관련 14건은 사람 검토 대상으로 표시됐다. 로컬 CLI 실행 방식과 필수 확인 문구의 관계를 확인해야 하며, 법적 확인과 심사 제출은 수행하지 않았다.
- OpenAI 디렉터리: 패키지 준비와 인증 게시자 확인 완료. 허용된 도구로 파일 선택을 완료할 수 없어 ZIP 업로드·심사 제출은 아직 하지 않았다.

GitHub 공개와 자체 marketplace 설치 제공은 완료됐으며, 두 공식 디렉터리 등재는 완료되지 않았다.
