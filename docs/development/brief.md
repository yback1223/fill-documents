# 문서 템플릿 제품 개발 기준

기준일: 2026-10-08 (Asia/Seoul)

## 사용자 확정 요구

- R1: 사용자 소유 브랜드로 문서 템플릿을 제공하고 요청 내용으로 문서를 채운다.
- R2: 한글 HWP를 포함한 여러 문서 형식을 대상으로 한다.
- R3: Claude와 Codex에서 모두 사용할 수 있게 한다.
- R4: GitHub 공개와 스킬, 플러그인, 마켓 배포를 준비한다.
- R5: 모든 Git 작업은 승인된 대상·행위·범위 안에서만 한다. 승인 범위는 아래 추가 사용자 확정 사항을 따른다.
- R6: Computer Use는 별도 승인 없이 사용하지 않는다.

## 추가 사용자 확정

- 1차 형식: HWP/HWPX/Word/PDF. XLSX/PPTX는 이번 범위에 포함하지 않는다.
- 공개 저장소: https://github.com/yback1223/fill-documents
- 사용자 브랜드의 오픈소스 프로젝트로 공개한다. 프로젝트 표기는 저장소에 맞춰 `fill-documents`로 사용한다.
- 이번 작업 동안 해당 저장소의 조회·복제·작업 브랜치 생성·커밋·푸시·PR 생성 승인. 강제 푸시·기존 이력 삭제·PR 병합 제외.
- 원격은 공개 빈 저장소였고 로컬 복제 후 첫 브랜치는 main으로 설정했다.

자체 코드·템플릿의 배포 라이선스는 MIT로 사용자 확정. 후속 확정한 게시자 표시명은 yback이며, 지원 가능한 모든 국가에 무료로 배포하고 제품 내 결제를 두지 않는다. 다크 모드 아이콘을 함께 제공한다. 공식 디렉터리의 본인 인증과 현재 정책 확인은 실제 신청 화면에서 별도로 완료해야 한다.

## 팀 제안

- 로컬 파일을 다루는 공용 엔진/CLI 하나를 스킬과 함께 배포한다. 별도 웹서비스나 데이터베이스 없이 시작한다.
- 플러그인은 같은 스킬·코드를 묶는다. Claude와 Codex의 manifest 및 marketplace 형식을 각각 제공한다.
- 내장된 자체 제작 서식과 사용자가 등록한 서식을 모두 지원한다.
- 지원 상태는 형식 이름 하나로 표시하지 않고 읽기, 필드 탐색, 채우기, 원래 형식 저장, 렌더/원본 앱 확인으로 나눈다.
- 어떤 문서에도 완전한 편집·서식 보존을 보장한다고 표시하지 않는다. 지원하지 않는 암호화, 서명, 매크로, 스캔 이미지 등의 경계는 실제 엔진에 따라 명시한다.
- AI는 사용자의 사실·의도와 문장을 판단하고, 결정적인 코드가 입력 검증과 파일 처리를 담당한다. 별도 모델 API 키나 특정 모델을 요구하지 않는다.
- 원본과 등록 템플릿은 보존하고 새 파일로 저장한다. 필수값 누락, 미확인 필드, 손상 입력, 형식 불일치, 실패 시 기존 출력 손실을 검증한다.
- 외부 오픈소스의 라이선스·저작권 고지를 유지한다. 설치된 Codex 전용 문서 런타임이나 비공개 자산은 제품 배포물에 복제하지 않는다.

## 완료 증거

| 요구 | 필요한 증거 |
| --- | --- |
| R1 | 내장 서식 목록 → 선택 → 입력 → 완성 파일의 실제 실행 및 읽기 검증 |
| R2 | 각 지원 형식의 정상/실패 테스트 및 명시적인 지원표 |
| R3 | 스킬 패키지 검증, 두 플랫폼 manifest 검증, 실제 실행 여부 구분 |
| R4 | 배포 ZIP 검증, 공개 주소 및 원격 결과 확인, 공식 디렉터리 심사 상태 구분 |

## 외부 배포의 구분

GitHub 공개, 자체 marketplace 공개, 공식 디렉터리에 심사 제출, 심사 승인 및 게시를 서로 다른 상태로 기록한다. ZIP 생성이나 저장소 업로드를 공식 마켓 게시 완료로 기록하지 않는다. 출판자 신원, 정책 URL, 지원 국가 및 배포 라이선스 등 미확정 사실을 만들어 넣지 않는다.

## 확인한 배포 근거

- OpenAI package format: https://developers.openai.com/plugins/build/plugins
- OpenAI Claude plugin compatibility: https://developers.openai.com/plugins/guides/submit-claude-plugin
- OpenAI public submission: https://developers.openai.com/plugins/deploy/submission
- Claude marketplace: https://code.claude.com/docs/en/plugin-marketplaces
- Claude plugins: https://code.claude.com/docs/en/plugins

초기 기획 당시 워크스페이스는 빈 디렉터리였다. 이후 사용자 승인으로 지정 저장소를 조회·복제했고 원격에 기존 커밋이 없음을 확인했다.
